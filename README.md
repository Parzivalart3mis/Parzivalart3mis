## 🚀 Featured Projects

- **[GatewayLLM](https://github.com/Parzivalart3mis/gatewayllm)** — OpenAI-compatible LLM Gateway — `Go` · `Redis` · `Qdrant` · `OpenTelemetry` · `Prometheus` · `Cloud Run`
  One stateless Go binary that routes across OpenAI, Groq and Gemini, with classified retry, failover and a Redis-Lua circuit breaker shared across replicas. A two-tier cache (Redis exact-match plus Qdrant at 0.95 cosine) serves hits at 0.42 ms p50 against 128 ms live calls, cutting spend 6× on a 180-request replay.
- **[PayGuard](https://github.com/Parzivalart3mis/payguard)** — Agentic Compliance Co-Pilot for Payment Disputes — `LangGraph` · `Qdrant` · `FastAPI` · `PostgreSQL` · `Redis` · `AWS ECS`
  A LangGraph multi-agent system drafts citation-grounded compliance language over hybrid retrieval: 0.91 RAGAS faithfulness and 38% faster median drafts on a 200-case benchmark. Human-in-the-loop gates mean the AI never finalizes anything, and RAGAS regression tests in CI stop quality from drifting. [Live Demo](https://payguard-pi.vercel.app/)
- **[TrustGuard](https://github.com/Parzivalart3mis/trust-guard)** — AI Abuse-Report Triage for Trust & Safety — `Python` · `FastAPI` · `Gemini` · `pgvector` · `React` · `Prometheus`
  Three single-purpose agents (classifier, severity scorer, action recommender) ground every decision in community guidelines via pgvector RAG. Prompt-injection detection, PII redaction before inference, and hard escalation rules: it can never auto-ban, and anything uncertain goes to a human. 296 tests at 89% coverage. [Live Demo](https://trust-guard-lime.vercel.app/)
- **[GitOps CI/CD Pipeline](https://github.com/Parzivalart3mis/gitops-cicd-pipeline)** — Commit to Production, Hands-Off — `GitHub Actions` · `Argo CD` · `Kubernetes` · `Docker` · `Prometheus` · `Grafana`
  GitHub Actions lints, tests, security-scans and ships versioned images; Argo CD keeps the cluster synced to Git. Dev → staging → prod promotion with approval gates and automatic rollback on failed health checks. [Live Demo](https://gitops-cicd-pipeline.vercel.app)
- **[Inflect](https://github.com/Parzivalart3mis/inflect)** — AI Language Coach — `Next.js` · `TypeScript` · `Gemini Live API` · `PostgreSQL` · `Redis`
  Grammar notebook, SM-2 spaced-repetition flashcards and a real-time voice coach on the Gemini Live API that quizzes you on your own cards. Ephemeral tokens keep the API key out of the browser. [Live Demo](https://inflect-zeta.vercel.app/)

**More I've shipped:** [TestForge](https://github.com/Parzivalart3mis/testforge) (self-service, PII-masked test data for Postgres) · [Kin](https://kin-xi-two.vercel.app) (one daily list of who to call) · [Tally](https://tally-blush-psi.vercel.app) (split a bill from a receipt, exactly) · [Reel](https://reel-wheat.vercel.app) (film & TV watchlist) · [MacroMap](https://macromap-ruby.vercel.app) (nutrition tracker) · [Rhythm](https://rhythm-rouge.vercel.app) (timetable with conflict detection)
